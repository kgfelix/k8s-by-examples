# Namespaces

 Namespaces provide a mechanism for isolating groups of resources within a single cluster.

 To create and manage Namespaces in Kubernetes, you can use either the declarative or the imperative method, depending on your operational needs.

 ### Example YAML file to create a Namespace

 ```yaml
 apiVersion: v1
kind: Namespace
metadata:
  name: staging
 ```

# Apply the file and create the Namespace:
```bash
kubectl apply -f namespace-example.yaml
```
# Create a Namespace imperatively:
```bash
kubectl create namespace staging
```

### View existing Namespaces
```bash
kubectl get namespaces
```
