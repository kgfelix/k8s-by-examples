# Kubeconfig and contexts

# Check if Colima is currently running
colima status

# Restart Colima explicitly enabling the Kubernetes cluster
colima start --kubernetes


kubectl create namespace my-environment



### Get Contexts

```sh
kubectl config get-contexts
```

### Check Current Context

```sh
kubectl config current-context
```

### Use Context

```shell
kubectl config use-context arn:aws:eks:us-east-1:524314025855:cluster/ps-microservices-staging

kubectl config use-context arn:aws:eks:us-east-1:524314025855:cluster/ps-microservices-production

kubectl config use-context arn:aws:eks:us-east-1:524314025855:cluster/data-science-production

kubectl config use-context arn:aws:eks:us-east-1:524314025855:cluster/data-science-staging

kubectl config use-context arn:aws:eks:us-east-1:524314025855:cluster/PSID
```

### Delete Context

```sh
kubectl config delete-context arn:aws:eks:us-east-1:524314025855:cluster/purespectrum-microservices-staging
```
